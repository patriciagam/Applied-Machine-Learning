# Applied Machine Learning

A collection of four machine learning assignments developed for the **APRE (Applied Predictive Analytics)** course. The project explores supervised and unsupervised learning techniques using Python and Scikit-learn, covering classification, regression, model evaluation, clustering, and dimensionality reduction.

## Assignments

### Homework 1 – Decision Trees & Feature Selection

Explored decision tree classification using the Pima Indians Diabetes dataset.

- Feature selection using ANOVA and Mutual Information.
- Decision Tree classification and visualization.
- Hyperparameter tuning using minimum sample split.
- Training vs. testing accuracy analysis.
- Model generalization and overfitting analysis.

**Dataset:** `diabetes.arff`

### Homework 2 – Classification & Model Evaluation

Compared classification algorithms using the Heart Disease dataset.

- k-Nearest Neighbors (kNN).
- Gaussian Naïve Bayes.
- Stratified 5-fold cross-validation.
- Min-Max feature scaling.
- Hyperparameter optimization and model comparison.
- Statistical hypothesis testing.
- Training and testing performance evaluation.

**Dataset:** `heart-disease.csv`

### Homework 3 – Regression & Neural Networks

Explored regression techniques to predict Parkinson's disease severity using biomedical measurements.

- Linear Regression.
- Multi-Layer Perceptron (MLP) Regressor.
- Neural networks with and without activation functions.
- ReLU activation and non-linear modelling.
- Mean Absolute Error (MAE) evaluation.
- Grid Search hyperparameter optimization.
- Model comparison across multiple train-test splits.

**Dataset:** `parkinsons.csv`

### Homework 4 – Clustering & Dimensionality Reduction

Applied unsupervised learning techniques to identify customer segments using banking data.

- Data preprocessing and Min-Max normalization.
- K-Means clustering.
- Elbow method and Sum of Squared Errors (SSE).
- Principal Component Analysis (PCA).
- Cluster visualization and interpretation.
- Customer segmentation and feature distribution analysis.
- Evaluation of clustering approaches for mixed-type data.

**Dataset:** `accounts.csv`
